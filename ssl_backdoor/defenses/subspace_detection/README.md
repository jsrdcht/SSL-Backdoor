# Subspace Detection

This module implements Song et al.'s ICLR 2026 paper,
[Test-Time Poisoned Sample Detection by Exploiting Shallow Malicious Matching in Backdoored
CLIP](https://openreview.net/forum?id=Kpij6oOnJl). It supports visual backdoor detection for Hugging
Face CLIP and SigLIP models. Text backdoors and vision-only encoders are outside its current scope.

## Usage

Install the project environment, update `model.checkpoint` and `data.image_root` in the config,
then run:

```bash
pixi run -e cuda python tools/run_subspace_detection.py \
  --config configs/subspace_detection/clip_backdoor.yaml
```

Use `configs/subspace_detection/badclip.yaml` for BadCLIP. The shell wrapper accepts the config as
its first argument and forwards the remaining options:

```bash
tools/run_subspace_detection.sh configs/subspace_detection/badclip.yaml --device cuda:0
```

Each run writes the resolved config, log, `metrics.json`, and per-sample `scores.csv`. `best_f1`
uses an oracle threshold for offline comparison only; `reference_threshold_f1` uses the maximum
score from the clean reference set as prescribed by the method.

`data.poisoned_csv` may point to a pre-generated poisoned set. Without it, the evaluator applies the
configured patch/blend trigger online. `data.reference_csv` may specify an independent clean
reference set; otherwise, reference samples are taken from the beginning of the clean test list and
evaluation starts immediately after them, ensuring the two sets do not overlap.

The files in `assets/subspace_detection_resources` contain the ImageNet validation manifest and
the text variants required by the detector. Actual images are resolved beneath `data.image_root`.
Bold and italic variants are deterministic Unicode transforms generated by the code.

## Reference regression results

These results were measured with epoch-10 poisoned checkpoints, 200 clean reference images, 1,000
clean images, and their 1,000 triggered counterparts:

| Attack | Clean accuracy | ASR | AUROC | Best F1 | Reference F1 |
|---|---:|---:|---:|---:|---:|
| CLIP-Backdoor | 0.538 | 0.989 | 0.8676 | 0.8646 | 0.0000 |
| BadCLIP | 0.523 | 0.956 | 0.9309 | 0.8911 | 0.0020 |

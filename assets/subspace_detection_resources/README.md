# ImageNet-1K text resources

- `imagenet1k_descriptions.csv`: six descriptions for each of 1,000 classes, with source notes.
- `imagenet1k_arabic_classes.txt`: 1,000 Arabic class names aligned by class index.
- `imagenet1k_val_labels.csv`: image filenames and labels for the 50,000-image validation set.

The descriptions cover 209 classes supplied by the original authors, one supplied class (`banana`)
corrected according to Table 1 of the paper, and 790 classes generated from the public prompt in
Appendix E.2. The generated descriptions are not claimed to match unpublished author outputs
verbatim.

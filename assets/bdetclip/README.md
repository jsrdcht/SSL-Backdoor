# BDetCLIP resources

`Benign_Imagenet1k.json` and `Malignant_Imagenet1k.txt` are prompt resources distributed by the
official [BDetCLIP implementation](https://github.com/Purshow/BDetCLIP). `badCLIP.jpg` is the trigger
used by the BadCLIP example config.
The upstream README limits its materials to non-commercial use with attribution; consult the
upstream repository before redistribution. See `ssl_backdoor/defenses/bdetclip/README.md` for usage
and attribution.
